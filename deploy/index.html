Your first formation

  1. Install WingMan and load your flight in MSFS 2024.
  2. Enter your pilot name once and click OK. WingMan connects automatically to MSFS and the relay; no formation code is needed.
  3. Enable Followable to appear in the pilot list.
  4. Select an aircraft marked Live, set your spacing, and switch Follow user on. Pale green rows are WingMan aircraft; light grey rows are MSFS-only traffic.

For reliable shared telemetry, each participating pilot runs WingMan. Search MSFS aircraft also lists local simulator contacts and visible player labels. Simulator-only aircraft can be followed when MSFS supplies a fresh position; Name only entries cannot yet be followed.

You control the aircraft’s autopilot master and autothrottle. WingMan updates the selected speed, heading and altitude outputs. For a 5 NM air train, each pilot follows the pilot immediately ahead. To circle a grounded WingMan lead, set a positive Above NM offset; Behind becomes the circle radius. Your own aircraft must be airborne.

The app checks for updates every five minutes. Automatic updates can be switched off; manual checking remains available.

Automatic setup: WingMan finds an existing compatible SimConnect runtime or downloads and verifies it automatically. No full SDK installation is needed. The Microsoft runtime retains its SDK licence.

Pilot names are supplied by pilots; they are not verified Xbox identities. Followable pilots share positions with nearby WingMan pilots and their followers. Unfollowable pilots send their position only to the relay for nearby discovery. The relay does not save telemetry to disk.
