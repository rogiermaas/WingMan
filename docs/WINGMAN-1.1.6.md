# WingMan 1.1.6

The main aircraft list now combines WingMan discovery with an optional **Search MSFS aircraft** scan. WingMan rows are pale green; simulator-only entries are light grey. A separate Source / data column distinguishes Live, Stale, No position and Name only. HUD labels cannot be followed until a real aircraft position is exposed. Fresh native IDs can be followed without a relay connection, while source namespaces prevent name/ID collisions. The list updates existing rows once per second, remains sortable, and has no hidden minimum-altitude filter. Searching does not stop active WingMan following, including when the optional map bridge is unavailable.

An airborne follower can circle a WingMan lead who is parked, taxiing or landing. Set a positive Above NM offset. Behind NM becomes the clockwise orbit radius; Right NM is retained for the next airborne follow. Takeoff automatically restores formation guidance after fresh airborne motion is established. Own-aircraft ground/500 ft AGL checks remain unchanged.

Orbit guidance uses ground position directly, so a stationary lead needs no invented heading or speed. Lead phase changes start a new motion regression, while absolute position-jump rejection remains active. Only the lead's own relay telemetry supplies authoritative ground status; native map flags remain diagnostic. Reacquisition and verified update resume both support a grounded lead.

Orbit speed is ten knots above the greater of the configured minimum IAS and 1.3 times the reported design stall speed, bounded by the same IAS/Mach ceilings. Radius grows when needed for a nominal 20-degree turn at current/commanded speed plus wind. This allows deceleration before tightening the circle; status reports any widening. Wind correction uses commanded airspeed. Height includes the normal own-aircraft barometric correction. The aircraft's actual bank limits and autopilot response determine the flown path; terrain clearance remains with the pilot.

Validation: 249 automated checks cover stationary acquisition, ground-only flag trust, zero/negative height rejection, live offset edits, taxi, landing/takeoff transitions, stale-data holds, automatic reacquisition, position jumps, IAS/Mach bounds, barometric height, and circle capture from inside/outside in a 20 kt crosswind with five-second heading response and a 25-degree bank limit. Both modeled captures settled within 0.2 NM of a 4 NM circle. Discovery checks cover source colours, source/ID/name collisions, label-only rejection, stale positions, 100 NM range, low-altitude inclusion, and a missing position becoming available on the same row. No live simulator circling result is claimed by these tests. The topmost regression fixture now separates cached TopMost setup from the ordinary-window activation check, avoiding setup activation in the bundled runtime; production window pinning is unchanged.

Release remains a single WingMan.exe auto-update plus a fresh per-user MSI and matching source download. No relay protocol or service change is required. Executable and MSI Authenticode signing status is unchanged; the update manifest is cryptographically verified.
